# 🎯 Shot Combo System - Executive Summary

## What Was Added

Three sequence-based shot combos to `modes/base/config/base.yaml` that unlock major gameplay features:

| Combo | Sequence | Unlocks | Reward |
|-------|----------|---------|--------|
| 🟢 **Ramp to Orbit** | Left Ramp → Right Orbit → Left Spinner | **Ball Lock** | 50K pts + 2x Multiplier |
| 🟢 **Loop** | L. Loop → R. Loop → Right Orbit | **Hurry Up** | 75K pts + 2x Multiplier |
| 💜 **Spinner Rampage** | L. Spinner → C. Spinner → R. Spinner | **Super Mode** | 100K pts + 3x Multiplier |

## Key Features

✅ **Three difficulty tiers**
- Easy: Ramp combo (5s window, wide targets)
- Medium: Loop combo (5s window, precision required)
- Hard: Spinner combo (4s window, most time-intensive)

✅ **Escalating rewards**
- Start with x2 multiplier
- Build to x3 multiplier  
- Unlock premium modes

✅ **Progressive unlock system**
- Ball lock starts locked (needs combo)
- Hurry ups trigger from loop combo
- Super modes available after spinner combo

✅ **Flexible event system**
- Each combo posts multiple events
- Other modes can listen and react
- Easy to extend with new features

## What You Need to Do

### Immediate (Required)

1. **Add player variables** to `config/player_variables.yaml`:
   - `playfield_multiplier` (default: 1)
   - `ball_lock_qualified_shots` (default: 0)

2. **Create show files** in `shows/`:
   - `off.yaml` - Turn off LEDs
   - `flash.yaml` - Flashing effect
   - `on.yaml` - Solid on

3. **Map LED tokens** in `config/lights.yaml`:
   - Define physical LED numbers for combo indicators
   - Map spinner/ramp/orbit arrow LEDs

### Soon (Recommended)

4. **Create event handlers** in related modes:
   - Ball lock mode listens for `ball_lock_qualification_started`
   - Hurry up mode listens for `hurry_up_mode_start`
   - Super mode listens for `super_mode_qualified`

5. **Test combos** thoroughly:
   - Manual testing in each sequence order
   - Verify time window behavior
   - Check variable updates

### Later (Enhancement)

6. **Tune difficulty**:
   - Adjust `delay_between` times if too easy/hard
   - Add more combos for variety
   - Create mode-specific combos

7. **Add visuals**:
   - Combo progress display
   - Celebration animation on complete
   - Mode-specific lighting themes

## Technical Summary

**Architecture:**
- Uses MPF's `sequence_shots` feature
- Tracks shot sequence order and timing
- Triggers events on completion
- Updates player variables

**Performance:**
- Minimal overhead (event-based)
- No polling required
- Scales well with many sequences

**Flexibility:**
- Easy to modify combo sequences
- Can be mode-specific
- Easily extended with new features
