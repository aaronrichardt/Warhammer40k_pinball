# 🎯 QUICK REFERENCE CARD - Shot Combos

## The Three Combos

### COMBO 1: 🟢 RAMP TO ORBIT
```
Left Ramp → Right Orbit → Left Spinner
⏱️  5 second windows
💰 50,000 pts
🔓 Ball Lock Unlocked
📈 Multiplier x2
```

### COMBO 2: 🟢 LOOP COMBO  
```
L. Inner Loop → R. Inner Loop → Right Orbit
⏱️  5 second windows
💰 75,000 pts
⏳ Hurry Up Activated
📈 Multiplier x2
```

### COMBO 3: 💜 SPINNER RAMPAGE
```
L. Spinner → C. Spinner → R. Spinner
⏱️  4 second windows
💰 100,000 pts
👑 Super Mode Unlocked
📈 Multiplier x3
```

---

## What Unlocks What

| Feature | Unlocked By | Effect |
|---------|------------|--------|
| **Ball Lock** | Ramp OR Loop combo | Can lock balls for multiball |
| **Hurry Up** | Loop combo | Time-limited scoring mode |
| **Super Mode** | Spinner combo | Premium gameplay features |
| **2x Multiplier** | Ramp OR Loop combo | All shots worth 2x |
| **3x Multiplier** | Spinner combo | All shots worth 3x |

## Switching & Events

| Shot | Switch | Combo |
|------|--------|-------|
| Left Ramp | s_left_ramp | Ramp combo (1/3) |
| Right Orbit | s_right_orbit | Ramp & Loop combos |
| Left Spinner | s_left_spinner | Ramp & Rampage combos |
| Center Spinner | s_center_spinner | Rampage combo (2/3) |
| Right Spinner | s_right_spinner | Rampage combo (3/3) |
| Left Loop | s_innerloop_left | Loop combo (1/3) |
| Right Loop | s_innerloop_right | Loop combo (2/3) |

## Time Window Explanation

```
Hit Shot 1
│
├─ [5 second window]
│
├─ Hit Shot 2 ✓ (within window)
│ │
│ ├─ [5 second window]
│ │
│ ├─ Hit Shot 3 ✓ (within window)
│ │
│ └─ COMBO COMPLETE!
│
└─ If Shot 2 not hit in time: Combo resets
```

## Troubleshooting One-Liners

| Problem | Solution |
|---------|----------|
| Combo won't trigger | Check shot names in base.yaml match defined shots |
| Events not posting | Verify event_player indentation is correct |
| Multiplier not updating | Ensure playfield_multiplier variable exists |
| Shows not playing | Check show files created in shows/ directory |
| LEDs not lighting | Verify combo_indicator LEDs defined in lights.yaml |
| Wrong sequence order | Review sequence shot order in base.yaml |
| Time window too tight | Increase delay_between (e.g., 5s → 6s) |
